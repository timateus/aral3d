# Aral in 3D — Documentation

**Live site:** https://aral3d.com  
**Preview:** https://aral3d.lovable.app

A 3D platform built on real terrain, hydrological and historical data of the Aral Sea region. It has **two modes**:

1. **Game** — a sequence of short, playable levels that teach the history, geography and hydrology of the Aral Sea through interaction. Educational tool first, video game second.
2. **Explore** — a GIS-like data exploration tool: real DEM, historical basins, demographic and climate layers, timeline, overlays, region bounds, shareable URLs.
